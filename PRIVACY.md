# Fill Pro Privacy Policy

Fill Pro is an open-source browser extension developed by toolls.io.

## 1. Local-First Processing
Fill Pro operates offline by default. All form discovery, semantic heuristics, synthetic data generation, and document generation occur entirely within your local browser sandbox.

## 2. Artificial Intelligence Integration
When you choose to enable Google Gemini AI:
- Fill Pro transmits only sanitized field metadata (field labels, input types, and section headers).
- Existing user-entered form data, passwords, OTPs, session identifiers, and cookies are never sent.
- API keys are stored in transient browser session storage and are never logged or stored externally.

## 3. Form Submission Safety
Fill Pro will never automatically click form submission buttons, trigger transactions, or execute destructive actions without explicit user interaction.
